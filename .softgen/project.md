# Saudi PropTech SaaS — Premium Property Operating System

## Vision
A flagship Saudi PropTech platform for 2026+ that unifies property management, reservations, hospitality operations, owner reporting, and rental workflows. Built for serious operators managing premium rental portfolios in Saudi Arabia. Arabic-first with equal English polish. Not a booking tool — an operating system.

Target users: Property managers, portfolio owners, accountants, housekeeping supervisors, maintenance teams, revenue managers running SAR 10M–200M+ rental operations.

## Features
1. **Landing Page** — premium SaaS hero with Saudi operator positioning, problem/solution, feature showcase, role-based benefits, AI intelligence, bilingual CTA
2. **Executive Dashboard** — realistic KPIs (revenue, occupancy, ADR, RevPAR), sophisticated charts (revenue trend, channel mix, occupancy), operational health, AI insights
3. **Properties & Units** — portfolio view, status indicators, occupancy snapshots, quick actions
4. **Calendar** — multi-property timeline, drag-drop reservations, channel colors, pricing overlays
5. **Reservations** — advanced filters, guest details, payment state, check-in/out status
6. **Channels** — OTA integration status, sync health, performance metrics
7. **Messages** — guest inbox, AI reply suggestions, channel source, SLA tracking
8. **Housekeeping** — task kanban, cleaner assignments, checklist progress, time windows
9. **Maintenance** — ticket workflow, severity, SLA, cost tracking
10. **Owners** — statements, revenue summary, payout cycles, unit contribution
11. **Finance** — VAT-aware reconciliation, owner balances, transaction timeline
12. **Reports** — portfolio analytics, channel performance, export capabilities
13. **Automations** — message rules, task triggers, pricing automation
14. **Settings** — workspace setup, roles, bilingual preferences, integrations
